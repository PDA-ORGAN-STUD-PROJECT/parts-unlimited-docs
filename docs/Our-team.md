# Наша команда

**PUL-Web** — команда разработки учебного проекта Parts Unlimited Lite в организации **PDA-ORGAN-STUD-PROJECT**.

| Участник или роль | Ответственность |
|---|---|
| Владелец организации dimer101 | Управление ресурсами организации |
| Участники команды PUL-Web | Изменение кода и документации в рамках выданных прав |
| Проверяющий | Просмотр предоставленных результатов и отчётов |

Фактическое членство и ожидающие приглашения проверяются в GitHub Teams. Приглашение само по себе не означает вступление в команду.
