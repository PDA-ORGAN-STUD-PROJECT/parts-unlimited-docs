# Начало работы

1. Войти в свой аккаунт GitHub.
2. Принять приглашение в организацию, если оно ещё ожидает ответа.
3. Проверить доступ к репозиторию приложения и Project.
4. Ознакомиться с [окружением разработки]({{ '/environment.html' | relative_url }}).

## Как изменить документацию

Файлы этого сайта хранятся в папке `docs`. Отредактируйте нужный Markdown-файл, сохраните изменение коммитом и дождитесь успешной публикации Pages.

```bash
git clone https://github.com/PDA-ORGAN-STUD-PROJECT/parts-unlimited-docs.git
cd parts-unlimited-docs
git status
```

Для каждой правки используйте понятное сообщение, например `docs: уточнены требования к окружению`. После изменения ссылок проверьте переходы между страницами.
